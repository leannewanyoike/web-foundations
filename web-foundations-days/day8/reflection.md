# Course Reflection: Web Foundations

Reflecting on the Web Foundations course, the most challenging concept was understanding concurrency control and database transaction isolation levels. In earlier exercises, logic executed sequentially and race conditions rarely manifested. However, when designing multi-user systems like seat reservations and inventory updates, grasping how concurrent transactions cause lost updates and double-bookings required a fundamental shift in thinking. I overcame this hurdle by setting up local PostgreSQL testing environments, intentionally triggering simultaneous transactions across separate terminal sessions using `SELECT ... FOR UPDATE`, and observing row lock states and serialization failures directly. This hands-on experimentation made abstract ACID properties concrete and intuitive.

For my capstone project, the most constructive feedback centered on request latency and asynchronous processing. Initially, my application handled third-party integrations and notification emails synchronously within the main HTTP request-response cycle, which introduced latency spikes and left the frontend vulnerable to external timeouts. Based on this feedback, I would improve the capstone by introducing an asynchronous job queue (such as Redis with background workers) alongside dead-letter queues for resilient retries. Offloading receipt generation, analytics tracking, and automated emails to background workers will keep API responses sub-100ms and significantly enhance user experience under heavy traffic.

Moving forward, I plan to expand my knowledge in distributed systems and modern cloud infrastructure. Specifically, I will learn event-driven architecture with Apache Kafka, container orchestration and autoscaling using Kubernetes, and advanced database tuning, including connection pooling with PgBouncer and table partitioning. These areas will build directly upon the architectural foundations gained in this course, enabling me to engineer resilient, high-throughput applications that reliably scale to millions of users.
