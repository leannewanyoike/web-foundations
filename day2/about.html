About QuickNotes

QuickNotes is a lightweight web application designed to help you capture your thoughts and ideas before they disappear. It provides a simple, fast, and distraction-free workspace for organizing your daily tasks and keeping track of important thoughts.

How to use QuickNotes

  1. Type your note into the "New note" input field on the Home page.
  2. Click the "Add Note" button or press Enter to save your note.
  3. Review your saved notes and track your total count under "Your notes".

Features

  • Instant note capturing without delays
  • Live counter tracking your total notes
  • Clean, distraction-free interface
  • Keyboard shortcuts for fast navigation

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Add a new note
Ctrl + N Focus note input field
Esc Clear current input
